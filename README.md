# Heart-Disease-Prediction
 Cardiac Risk Assessment using Machine Learning

📌 Overview

The Cardiac Risk Assessment project is a web-based application that predicts the likelihood of heart disease using a Logistic Regression machine learning model trained on the UCI Cleveland Heart Disease Dataset.

The application provides an intuitive clinical-style interface where users can enter patient information and receive a predicted probability of heart disease along with an explanation of the most influential features contributing to the prediction.

«Note: This project is developed for educational and research purposes only. It is not a certified medical diagnostic tool.»

📊 Dataset

Dataset: UCI Cleveland Heart Disease Dataset

The dataset contains patient medical records including:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression (Oldpeak)
- ST Slope
- Number of Major Vessels
- Thalassemia

🤖 Machine Learning Model

Algorithm Used:

- Logistic Regression

Model Performance:

- Test Accuracy: 85.2%
- ROC-AUC Score: 0.894

🚀 Getting Started

1. Clone the repository

git clone https://github.com/your-username/Cardiac-Risk-Assessment.git

2. Navigate into the project folder

cd Cardiac-Risk-Assessment

3. Open "index.html" in your browser.

No additional installation is required for the frontend.

---

📈 Workflow

1. Enter patient clinical information.
2. The input is preprocessed.
3. The Logistic Regression model calculates disease probability.
4. The application displays:
   - Prediction
   - Risk percentage
   - ECG visualization
   - Top contributing factors
